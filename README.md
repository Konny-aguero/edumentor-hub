# EduMentor Hub

**Universidad de Costa Rica**

**Curso: IF0009 Desarrollo de Software IV**

EduMentor Hub será una plataforma web de tutorías académicas para gestionar estudiantes, tutores, materias, disponibilidad de horarios, reservas de tutorías, recursos de estudio y evaluaciones.

## Tecnologías previstas

- Backend: Java 21, Spring Boot 3, Spring Data JPA y Spring Security con JWT.
- Frontend: Angular 17 o superior con Standalone Components.
- Base de datos: relacional.
- Pruebas unitarias: JUnit 5 y Mockito.
- Documentación: diagramas ERD, UML y especificación OpenAPI 3.0.
- Control de versiones: GitHub Flow.
